# CursorでWeb制作のMVPを2時間で作る：プロンプト1つでLP完成までの実践

中小企業のWebサイト担当者とよく話すテーマがあります。「とりあえず形を見せたい」「広告を回す前にLPが欲しい」。外注すると2週間、社内で作ろうとすると時間がかかる。そんな課題を、Cursor（AIエディタ）とClaude 3.5 Sonnetモデルで解決する事例を紹介します。

## Cursorとは

CursorはAIを統合したコードエディタです。自然言語の指示でHTML/CSS/JS、Next.js、React等のコードを生成し、ブラウザでのプレビューも内蔵しています。APIキー（OpenAI/Gemini/Claude系）を設定することで、自前のプロンプトで自由に開発できます。私はプロンプトにClaude 3.5 Sonnet系のモデルを指定し、コストを抑えつつ精度の高いコード生成を実現しています。

## 実際の開発フロー（2時間でLP作成）

### 1. プロンプトで「枠」を作る（20分）

最初に、仕様書とAPIキー、デザイン方針をまとめたプロンプトを用意します。

```text
以下の仕様でランディングページを作ってください。
- 目的：新商品の予約販売受け付け
- 構成：ヒーロー、特徴3点、お客様の声、FAQ、申し込みフォーム
- デザイン：青を基調とし、シンプルで信頼感のある印象
- 画像：プレースホルダーで良いので画像領域を明記
- レスポンシブ対応
```

Cursorはコンテキストを保持しながらコードを出力します。1回のプロンプトで骨格ができるため、手動でHTMLを書くよりも圧倒的に速いです。

### 2. プレビューで調整（30分）

Cursorの内蔵ブラウザでリアルタイムに確認しながら、色・余白・フォントを微調整します。CSS変数を使っているため、1箇所変更すれば全体に反映され、見栄えの調整がスムーズです。画像のプレースホルダーも配置した後、実際の画像に差し替えれば完成です。

### 3. 本番化（30分）

静的なLP完成后、WordPressサイトに組み込む場合は、WordPressのテーマディレクトリにファイルを転送し、ショートコードや固定ページとして登録します。ただし、LPは単体で十分に機能するため、Vercel等にデプロイして一時公開するケースも多いです。

### 4. クライアント確認と修正（40分）

ここまで来ると、すでに「動くLP」が存在するため、フィードバックは「ここを青にして」「FAQを追加」といった具体的な修正指示に集約されます。ヒアリング→修正→確認のサイクルが早くなり、結果として2時間程度でMVP（実用最小限の製品）として成立します。

## 効果とメリット

| 項目 | 従来の外注 | Cursor活用 |
|------|-----------|-----------|
| かかる時間 | 2〜4日 | 2〜3時間 |
| 修正レスポンス | メールでの往復 | リアルタイム |
| コスト | 10〜30万円 | 数万円（保守含まず） |
| ブラウザ確認 | 別環境が必要 | 内蔵プレビュー |

重要なのは、このLPを「本番として使うか」ではなく「需要を検証するか」に価値を置いている点です。広告を流す前にCursorでLPを完成させ、Google Analytics等でコンバージョンレートを測定。数値が取れてから外注で本格化、という手が打てます。

## 注意点

Cursorは強力ですが、プロンプトの品質が出力に直結します。仕様を明確にし、デザインの参考URLを添えればより精度が上がります。また、複雑なCMS連携や決済処理は別途実装が必要です。最初は「静的な情報提供LP」としてCursorの能力を最大限に活用し、徐々に範囲を広げる運用をお勧めします。

## まとめ

Web制作において「形にするまでの速度」は競争力です。特に中小企業のDX予算は限られており、スピード感を持った検証サイクルが重要になります。Cursorはそのための強力な道具ですが、使う人（制作側）のプロンプト力と、何を作るか（テストしたい仮説）の両方が揃って初めて価値を発揮します。
