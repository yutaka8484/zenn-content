## はじめに
株式会社コバヤシでは、社内サーバーにAIエージェントを導入し、毎日の業務を自動化しています。この記事では、導入の背景、システムの構成、設計判断、ハマった点などについて詳しく説明します。

## 課題提起
従来、社内業務では、書類の整理、毎日の定時レポート、サーバーの監視など、人を雇うほどではないが確実に時間を奪う仕事が多くありました。これらの業務を効率化するために、AIエージェントの導入を決定しました。

## システムの構成
社内サーバーには、AIエージェントが常駐し、毎日決まった時間に決まった仕事をこなしています。現在、AIエージェントが毎日行っている仕事の一部は以下のとおりです。

| 時刻 | 仕事 |
|---|---|
| 深夜〜早朝 | サーバー内の書類・資料の整理と記録の更新 |
| 早朝 | 各端末から送られたファイルを種類ごとに仕分け |
| 朝 | 業界ニュースを要約した朝刊レポートを配信 |
| 夜 | その日の業務状況をまとめた日報を配信 |
| 2時間ごと | 社内システムの健康チェック（異常があれば即通知） |

## 実装
AIエージェントの実装には、Pythonを使用しました。具体的には、次のライブラリを使用しました。

* `schedule`：ジョブスケジューリング
* `pandas`：データ分析
* `numpy`：数値計算
* `scikit-learn`：機械学習

### 例: 書類整理ジョブ
```python
import schedule
import time
import pandas as pd

def document_sorting():
    # 書類データを読み込み
    documents = pd.read_csv('documents.csv')
    
    # 書類を種類ごとに仕分け
    documents_sorted = documents.sort_values(by='category')
    
    # 整理された書類を保存
    documents_sorted.to_csv('documents_sorted.csv', index=False)

schedule.every(1).day.at("08:00").do(document_sorting)  # 毎日8時に実行
```

## 運用の設計判断
AIエージェントの運用では、次の原則で設計判断を行っています。

* **定型はAIに、判断は人に**：毎日同じ手順の仕事だけをAIエージェントに任せ、金額や取引に関わる判断は必ず人が行います
* **結果は必ず報告させる**：AIエージェントが行った仕事の結果は、必ず報告させます
* **失敗しても壊れない範囲から**：AIエージェントに任せる仕事は、失敗しても社内システムが壊れない範囲から始めます

## ハマった点
AIエージェントの導入・運用でハマった点は、次のとおりです。

* **初期の設定が重要**：AIエージェントの設定が不十分だと、予期せぬエラーが発生することがあります
* **ジョブの優先順位**：ジョブの優先順位を適切に設定しないと、重要なジョブが遅れて実行されることがあります
