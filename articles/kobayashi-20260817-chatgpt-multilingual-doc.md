## 製造現場の多言語ドキュメントが抱える課題

製造業の現場では、海外工場との連携や外国人材の増加に伴い、作業マニュアルやFAQを複数言語で用意する必要が生じている。従来は専門の翻訳会社に外注するか、担当者が手作業で翻訳ソフトと辞書を往復しながら文書を作成しており、更新のたびに数日から数週間のリードタイムがかかることが珍しくなかった。特に加工現場では、安全に関わる手順書を迅速かつ正確に多言語展開する必要があり、翻訳の遅れがそのまま安全教育の遅れにつながるという課題がある。さらに、手順書は一度作って終わりではなく、工程変更や設備更新のたびに全言語版を追随させる必要があるため、外注中心の運用ではメンテナンスコストが積み上がりやすい。近年はChatGPTのような対話型AIを使い、下書き作成・用語統一・多言語翻訳を一つの流れで行う手法が公開情報として広く紹介されるようになってきた。本稿では、製造業の現場でChatGPTを使って作業マニュアルやFAQを短時間で作成・翻訳する際の考え方と、実務で使えるプロンプト例を整理する。

## ChatGPTで作業マニュアルの下書きを高速化する

既存の作業手順を箇条書きでChatGPTに渡し、規定のフォーマット(目的・準備物・手順・注意事項)に沿って文章化させると、担当者が一から文章を組み立てるより短時間でドラフトが得られるはずだ。ポイントは、①現場の専門用語をあらかじめ辞書として渡す、②想定読者(新人作業者か海外拠点のオペレーターか)を明示する、③安全上の注意事項を独立した項目として必ず出力させる、の3点にある。曖昧な指示だと一般的な文章になりがちなので、フォーマットと用語辞書を毎回同じ形で渡せるよう、プロンプトはテンプレート化しておくと指示コストを下げられる。

```text
あなたは製造業の技術文書ライターです。
以下の箇条書き手順を、次のフォーマットで文章化してください。

# 用語辞書
- 治具 → jig
- 面取り → chamfering
- 送り速度 → feed rate

# フォーマット
1. 目的
2. 準備物(工具・材料)
3. 手順(番号付き、1手順1文)
4. 注意事項(安全・品質に関わる項目のみ)

# 手順メモ
{ここに現場の箇条書きメモを貼り付け}
```

このように入力と出力の形を固定しておくと、担当者が変わっても同じ品質のドラフトを再現しやすくなる。

## 多言語翻訳とFAQ化のワークフロー

日本語ドラフトができた後、同じ会話の中で「英語・中国語・ベトナム語に翻訳してください。ただし専門用語は上記の用語辞書に従ってください」と続けて指示すると、文脈を保ったまま多言語版を作れるはずだ。単発の一括翻訳ツールと違って対話形式のため、翻訳結果に対して「この手順は現場の初心者にも伝わる表現か確認してください」「安全に関わる文はより強い注意喚起の言い回しにしてください」と追加で聞き直せる点が強みになる。FAQについても、現場から寄せられる質問リストをそのまま貼り付け、「回答案を作成し、既存マニュアルと矛盾がないか確認してください」と指示すれば、マニュアルとFAQの整合性を保ちながら多言語版を同時に用意できるはずだ。

```text
上記マニュアルの内容と矛盾しないよう、
以下のFAQに日英中越4言語で回答案を作成してください。
数値(寸法・温度・時間)はマニュアル記載の値と完全に一致させてください。

Q1: 面取り加工で工具が発熱したときはどうすればよいか
Q2: 治具の交換タイミングの目安は
```

## 運用で気をつけたいポイント

ChatGPTが生成する文章は流暢だが、現場の実情と食い違う場合があるため、公開前には必ず現場の一次責任者、可能であれば対象言語のネイティブ話者によるレビューを挟む運用が欠かせないはずだ。特に安全確認の言い回しや数値(トルク値、温度、時間)は、AIが自然な文章に整える過程で丸められたり誤変換されたりするリスクがあるため、数値部分だけは原文と機械的に突き合わせるチェック工程を設けるべきだろう。また、用語辞書やフォーマットのテンプレートは社内でバージョン管理しておくと、担当者が変わっても同じ指示を再現でき、文書間の表記ゆれも防ぎやすくなる。翻訳の正しさとは別に、「現場の作業者が実際にその通り動けるか」という観点のレビューを分けて考えることが、品質を保つ上での実務的なコツになるはずだ。

## まとめ

多言語マニュアル・FAQの作成は、これまで翻訳会社や語学人材への外注に頼らざるを得ない業務だったが、ChatGPTのような対話型AIを使えば、下書き作成・用語統一・多言語翻訳・FAQ整合性チェックまでを一つの流れで進められるはずだ。重要なのはAIに丸投げすることではなく、用語辞書とレビュー工程を運用フローに組み込み、現場の安全性と正確性を人の目で担保すること。テンプレートと辞書さえ整えてしまえば、更新のたびに外注のリードタイムを待つ必要がなくなり、現場の変化に文書がついていきやすくなる。
