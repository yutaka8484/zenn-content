Claude Code、Cursor、Codex などのAIコーディングエージェントを使うとき、**「どのファイルを読めばいいか」** を探る過程でトークンを大量消費していないだろうか。私も株式会社コバヤシとして製造業のDX案件に携わり、基幹システムの改修では数千ファイルのリポジトリをAIに探索させている。

この「探索コスト」を削減するツールが **CodeGraph** だ。本記事では導入方法と効果を共有する。

## AIエージェントの「探索」という弱点

AIエージェントはコード構造を把握するために `grep`、`glob`、`Read` を繰り返す。file-by-fileの探索は**大規模リポジトリほどトークン消費とレイテンシを肥大化させる**。

私が手がけた基幹システム入れ替えPJでは、受注・生産・請求システムが数百ファイルに散在していた。AIに「請求フローを追って」と依頼すると、延々とファイルを読み同じ構造を何度もスキャンする。**1回の質問で数万〜10万トークンを消費**するケースもあった。

## CodeGraphで知識グラフをローカル構築

CodeGraphはtree-sitterでソースコードをASTに分解し、シンボル関係・呼び出しグラフを**ローカルのSQLite**に格納する。主要特徴：

- **トークン16%削減、ツール呼び出し58%削減**（7リポジトリのベンチマーク）
- **ローカル完結**：APIキー不要、データ外部送出なし
- **自動同期**：ファイル監視で2秒後にインデックスを自動更新
- **20+言語対応**：TypeScript、Python、Go、Rust、Javaなど
- **Claude Code / Cursor / Codex / Hermes Agent 統合**

## 導入はワンライナー、プロジェクト初期化も1コマンド

Node.js不要で、curl/PowerShell一発で導入できる：

```bash
curl -fsSL https://raw.githubusercontent.com/colbymchenry/codegraph/main/install.sh | sh
codegraph install --yes --target=claude,hermes
```

各プロジェクトでは以下を実行するだけ：

```bash
cd /opt/data/projects/client-system
codegraph init
```

`.codegraph/` が作成され、auto-syncが有効になる。

## ベンチマーク：エージェントはどう速くなったか

Claude Opus 4.8 (headless) で7つの実リポジトリをテストした結果、**平均でトークン47%削減、ツール呼び出し58%削減、22%高速化** を記録している。

| リポジトリ | 言語 | コスト削減 | トークン削減 | 高速化 | ツール呼び出し削減 |
|------------|------|------------|--------------|--------|--------------------|
| VS Code | TypeScript | 18% | 64% | 11% | 81% |
| Django | Python | 8% | 60% | 13% | 77% |
| Alamofire | Swift | 40% | 64% | 33% | 58% |

特に大規模リポジトリほど効果が大きく、VS Codeではファイル読み取り回数が**0**、grep/bash呼び出しも**0**になった。

## x1liteでの運用：製造業DXに適した設計

私は開発環境をBeelink EliteMini (x1lite) + Ubuntu 24.04 + Dockerで構築している。CodeGraphはホスト側にローカルインストールし、Hermes AgentやClaude Codeから直接参照する。

ポイントは**インデックスをプロジェクトごとに閉じ、リモート送信を一切行わない**設計だ。製造業のクライアント案件では、顧客ソースコードを手元から出さずAI支援する必要があるが、CodeGraphはその要件に自然に適合する。

```bash
codegraph explore "認証ミドルウェアの呼び出し元を追う"
```

1回のクエリで関連シンボルとソーススニペットが返ってくる。

## まとめ：開発のデータ主権を取り戻す

AIエージェントの利用増加とともに、**探索コストの分散とトークン消費の爆発**は深刻化する。CodeGraphは、この問題をローカル・オフラインで解決するシンプルなOSSだ。

私の考えるDXは「高価なクラウドに依存せず、社内の資産を主権を持って管理する」こと。CodeGraphは開発環境への自然な導入例だ。
