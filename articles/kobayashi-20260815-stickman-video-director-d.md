## 作業手順書が「読まれない」という現場の課題

木工所の生産現場では、加工手順や治具の使い方、安全確認のポイントをまとめた作業手順書が数多く存在します。しかし紙やPDFの手順書は、文章と静止画だけでは動きや力加減、タイミングといった「時間軸を伴う情報」を伝えきれません。特に外国人材や未経験の新人にとっては、文字の手順書を読んでから頭の中で動作に変換する負担が大きく、結局は先輩の背中を見て覚えるという属人的な教育に戻ってしまいがちです。

株式会社コバヤシでも、製造業のデジタル化を自社実践する中で、手順書を「読ませる」から「見せる」へ切り替える必要性を感じてきました。動画マニュアルは有効な手段ですが、実写撮影は照明やモデルの手配、撮り直しのコストがかかり、手順が変わるたびに再撮影が発生する点がネックになります。ここで候補になるのが、スティックマンアバターによる動画生成を扱うOSSプロジェクト「Stickman Video Director」です。実写を使わずに手順を可視化できれば、変更への追従コストを大きく下げられるはずです。

## Stickman Video Directorとは何か

Stickman Video Directorは、シンプルな棒人間(スティックマン)アバターを使って動画コンテンツを制作できるGitHub上のプロジェクトです。複雑なアニメーション制作スキルを前提とせず、手軽に動画を作れる設計になっている点が特徴として公開情報から読み取れます。実写のように顔や服装の情報が写り込まないため、作業者のプライバシーに配慮しながら動作そのものに注目を集められる、という利点も見込めます。

製造業の教育資料という文脈で見ると、スティックマン表現は「誰が」ではなく「どう動くか」を強調できる点が相性が良いと考えられます。手順書に書かれている「部材を両手で保持し、治具に沿わせてスライドさせる」といった動作を、実写より抽象化された形で繰り返し提示できれば、動作の型を覚えさせる教材として機能するはずです。もっとも、これは公開情報に基づく検討であり、実運用での精度や表現力の限界は個別に検証する必要があります。

## 手順書テキストからシーンを組み立てるワークフロー

実際に導入を検討する場合、まず既存の作業手順書をシーン単位に分解する下準備が必要になります。手順書の各ステップを「動作」「対象物」「持続時間」に分けて構造化しておくと、動画生成側への入力として扱いやすくなるはずです。イメージとしては、以下のような中間フォーマットを用意する流れが考えられます。

```yaml
# procedure_scene.yaml
scene:
  - step: 1
    action: "部材を両手で持ち上げる"
    target: "集成材パネル"
    duration_sec: 3
  - step: 2
    action: "治具に沿わせて水平にスライドさせる"
    target: "集成材パネル"
    duration_sec: 5
  - step: 3
    action: "クランプで固定し安全確認を行う"
    target: "治具"
    duration_sec: 4
```

このようなステップ定義を用意しておけば、Stickman Video Director側の生成処理に渡すインプットとして再利用しやすく、手順が改訂された際もYAMLの該当行を修正するだけで動画を再生成できる見込みです。手順書のマスターデータをテキストベースで一元管理し、そこから動画という表現形式を都度書き出す、という構図にできる点が、実写撮影運用との大きな違いになるはずです。

## 現場導入で検討すべきポイント

動画マニュアル化を検討する上で、技術的な生成品質と同じくらい重要なのが運用面の設計です。第一に、安全に関わる注意喚起(手を挟まない、保護具を着用するなど)は、スティックマン表現だけでは伝わりにくい可能性があるため、テロップや音声ガイダンスを併用する設計にしておくのが無難だと考えられます。第二に、多言語対応です。技能実習生や海外人材が多い現場では、同じ動作の映像に対して字幕だけを差し替える運用ができれば、翻訳コストを抑えつつ多言語マニュアルを展開できるはずです。

第三に、既存の手順書管理システムとの接続です。手順書がExcelや紙で管理されている場合、まずテキストデータ化して構造化する工程がボトルネックになりがちです。次のような簡易スクリプトで、Excelの手順表からシーン定義のたたき台を自動生成しておくと、動画化の着手障壁を下げられると考えられます。

```python
import openpyxl

def export_scene_draft(xlsx_path, sheet_name="手順"):
    wb = openpyxl.load_workbook(xlsx_path)
    ws = wb[sheet_name]
    scenes = []
    for row in ws.iter_rows(min_row=2, values_only=True):
        step, action, target, duration = row[:4]
        if action:
            scenes.append({
                "step": step, "action": action,
                "target": target, "duration_sec": duration or 4
            })
    return scenes
```

このように、手順書の構造化とシーン変換の自動化を組み合わせておくことが、動画マニュアル運用を継続させる鍵になると見ています。

## まとめ

作業手順書を動画化する取り組みは、教育コストの削減だけでなく、手順の標準化そのものを促す効果も期待できます。Stickman Video Directorのようなスティックマンアバターを使うアプローチは、実写撮影の手間を避けつつ、動作の型を繰り返し提示できる点で製造業の教育資料と親和性が高いと考えられます。ただし安全表示や多言語対応、既存データとの接続といった運用設計を並行して詰めておかないと、動画を作ること自体が目的化してしまうリスクもあります。テキストベースの手順マスターを起点に、そこから動画という出力形式を生成する構造を作っておくことが、変化に強いマニュアル運用につながるはずです。
